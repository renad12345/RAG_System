نظام **RAG (Retrieval-Augmented Generation)** عملي، احترافي، وسهل الاستخدام، مبني خصيصاً للاستعلام عن مخاطر وسيناريوهات الأمان في تطبيقات الذكاء الاصطناعي استناداً إلى الوثيقة الرسمية الأحدث:
**OWASP Top 10 for LLM Applications 2025 (Version 2025 - الصادرة بتاريخ 18 نوفمبر 2024)**.

## 🌟 أبرز مميزات النظام

1. **الاستناد التام إلى المصدر (Zero Hallucination):**
   - استخراج وتوثيق النصوص الرسمية مباشرة دون اختراع أو تأليف أي معلومة خارج الوثيقة.
2. **ذكر أرقام الصفحات بدقة (Exact Citations):**
   - لكل خطر أو سيناريو، يوضح النظام أرقام الصفحات الدقيقة في وثيقة OWASP 2025 الرسمية (مثلاً: Prompt Injection في الصفحات 3 - 6).
3. **نظام التحقق والموثوقية (Grounded Verification Engine):**
   - فحص آلي لمطابقة المخرجات مع معايير ثالوث الـ RAG:
     - **Context Relevance (صلة السياق):** التأكد من مطابقة الوثيقة المسترجعة للاستفسار.
     - **Groundedness / Faithfulness (المطابقة للمصدر):** التحقق من أن كل توصية وسيناريو مأخوذ من النص الأصلي.
     - **Answer Relevance (شمولية الإجابة):** التأكد من اشتمال الرد على التصنيف، الوصف، طرق الوقاية، وسيناريوهات الهجوم.
4. **تغطية شاملة للمخاطر العشرة (2025):**
   - **LLM01:2025** حقن التوجيهات (Prompt Injection) — الصفحات 3 - 6
   - **LLM02:2025** تسريب المعلومات الحساسة (Sensitive Information Disclosure) — الصفحات 7 - 10
   - **LLM03:2025** مخاطر سلاسل الإمداد (Supply Chain) — الصفحات 11 - 15
   - **LLM04:2025** تسميم البيانات والنماذج (Data and Model Poisoning) — الصفحات 16 - 18
   - **LLM05:2025** المعالجة غير الآمنة للمخرجات (Improper Output Handling) — الصفحات 19 - 21
   - **LLM06:2025** الوكالة والصلاحيات المفرطة (Excessive Agency) — الصفحات 22 - 25
   - **LLM07:2025** تسريب موجه النظام (System Prompt Leakage) — الصفحات 26 - 28
   - **LLM08:2025** نقاط ضعف المتجهات والتضمين في RAG (Vector and Embedding Weaknesses) — الصفحات 29 - 31
   - **LLM09:2025** المعلومات المضللة والهلوسة (Misinformation) — الصفحات 32 - 34
   - **LLM10:2025** الاستهلاك غير المنضبط للموارد والتكاليف (Unbounded Consumption) — الصفحات 35 - 38
5. **البحث الهجين الثنائي (Hybrid Arabic/English Search):**
   - يقبل اسم الخطر بالإنجليزي أو العربي، أو وصف سيناريو واقعي (مثل: "نص أبيض مخفي في سيرة ذاتية"، "شات بوت طيران كندا"، "استهلاك مالي عالي").
6. **واجهة مستخدم احترافية باللغة العربية (RTL):**
   - مبنية بـ Streamlit مع دعم الاتجاه العربي، بطاقات مؤشرات الأداء، تبويبات تفاعلية، وأزرار تجربة سريعة للسيناريوهات.
7. **تصدير التقارير:**
   - إمكانية تحميل التقرير الكامل كملف Markdown أو JSON بنقرة واحدة.

## 🚀 طريقة التشغيل المحلي (Run Locally)

1. **تثبيت المتطلبات:**
   ```bash
   pip install -r requirements.txt
   ```

2. **تشغيل التطبيق:**
   ```bash
   streamlit run app.py
   ```

3. **فتح الرابط في المتصفح:**
   - سيفتح التطبيق تلقائياً على: `http://localhost:8501`

## ☁️ طريقة الرفع والنشر على الـ STR (Streamlit Community Cloud)

1. قم بإنشاء مستودع جديد على **GitHub** وارفع عليه ملفات المشروع.
2. ادخل على منصة **[share.streamlit.io](https://share.streamlit.io/)**.
3. اختر المستودع الخاص بك، وحدد الملف الرئيسي: `app.py`.
4. اضغط على **Deploy**؛ سيتم تثبيت الحزم من `requirements.txt` ونشر التطبيق فوراً برابط عام يمكنك مشاركته!
